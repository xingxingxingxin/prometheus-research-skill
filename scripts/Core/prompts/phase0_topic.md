# Phase 0: Topic Analysis

> 研究主题分析阶段 - 明确研究方向和目标

## 阶段目标

分析研究主题，提取核心研究方向、关键概念和研究问题，为后续文献调研和假设设计奠定基础。

## 输入

- 研究主题: 由用户提供的研究领域或问题
- 项目目录: `Projects/{project_name}/`

## 输出目录结构

```
Projects/{project_name}/
├── notes/
│   ├── topic_analysis.md      # 主题分析报告
│   ├── research_fields.md     # 研究领域识别
│   ├── research_goals.md      # 研究目标
│   └── research_roadmap.md    # 研究路线图
└── state.json                 # 更新状态
```

## 任务清单

### T001: 分析研究主题
- 提取核心研究方向
- 识别关键概念和术语
- 明确主要研究问题

### T002: 识别研究领域
- 确定主要研究领域
- 识别交叉学科
- 分析领域间的关联

### T003: 明确研究目标
- 定义具体研究目标
- 说明预期贡献
- 评估可行性

### T004: 制定研究计划
- 设计技术路线
- 规划时间节点
- 识别潜在风险

## 工作流程

1. **主题解析**
   - 分析研究主题的关键词
   - 提取核心概念
   - 识别研究边界

2. **领域调研**
   - 确定主要研究领域
   - 识别相关交叉学科
   - 分析领域发展趋势

3. **目标设定**
   - 定义 SMART 研究目标
   - 明确预期贡献
   - 评估资源和时间

4. **路线规划**
   - 设计研究技术路线
   - 制定里程碑计划
   - 识别风险和应对策略
