## STEP 2: 假设形式化

### 2.1 假设构建框架

一个好的假设应该满足以下标准：

```
SMART 原则:
- Specific (具体): 明确说明预期关系
- Measurable (可测量): 可以用实验验证
- Achievable (可实现): 技术上可行
- Relevant (相关): 对研究问题有直接贡献
- Time-bound (有时限): 能在有限时间内验证
```

### 2.2 假设类型识别

根据研究性质选择假设类型：

1. **因果假设** (Causal):
   - 格式: "X 导致 Y 因为..."
   - 示例: "引入注意力机制可以提高时序预测准确率，因为它能捕捉长程依赖"

2. **相关假设** (Correlational):
   - 格式: "X 与 Y 相关"
   - 示例: "模型复杂度与过拟合风险正相关"

3. **比较假设** (Comparative):
   - 格式: "方法 A 比方法 B 在 X 方面更好"
   - 示例: "Transformer 在长序列预测上优于 LSTM"

4. **机制假设** (Mechanistic):
   - 格式: "X 通过机制 Y 实现 Z"
   - 示例: "Dropout 通过随机失活减少神经元共适应"

### 2.3 假设模板

```markdown
# 假设: [假设编号]

## 假设陈述

- 理论依据: [为什么我们认为这是对的]
- 预期效应: [预期的效果大小和方向]

## 变量定义

- 控制变量 (CV): [需要保持恒定的变量]
  - 为什么控制: [影响机制]

## 可证伪性
```

### 2.4 假设示例

```markdown
# 假设: H1

## 假设陈述
**H1**: 在多变量时序预测任务中，引入跨变量注意力机制相比独立变量建模，
      可以将预测误差降低 10-15%，特别是在变量间存在强相关性的场景下。

## 理论基础
- 基于文献:
  - [论文1] 显示变量间相关性蕴含重要信息
  - [论文2] 表明跨维度注意力在某些任务上有效
- 理论依据: 当变量间存在因果关系或共同驱动因素时，
            联合建模能捕捉这些依赖关系
- 预期效应: 中等到大效应 (Cohen's d > 0.5)

## 变量定义
- 自变量 (IV): 注意力机制类型
  - 操作定义:
    - 组1: 独立变量建模 (baseline)
    - 组2: 跨变量注意力 (treatment)
- 因变量 (DV): 预测准确率
  - 操作定义: 在测试集上的 MAE
  - 测量指标: MAE, RMSE, MAPE
- 控制变量 (CV):
  - 模型架构深度 (控制为相同层数)
  - 参数量 (保持相近)
  - 训练数据 (使用相同数据集)
  - 超参数 (使用相同的调优程序)

## 可证伪性
- 如果跨变量注意力的 MAE 降低 < 5% 或统计不显著 (p > 0.05)
- 如果在低相关性数据集上性能下降 > 10%

## 依赖假设
- 假设 A: 数据集中存在可利用的变量间依赖
- 假设 B: 现有计算资源足以支持更复杂的注意力计算

## 风险评估
- 可能不成立的原因:
  - 变量间相关性可能较弱或为噪声
  - 增加的复杂度可能导致过拟合
- 替代解释:
  - 性能提升可能来自参数增加而非机制本身
  - 需要通过消融实验排除
```

## STEP 5: 风险评估与缓解

### 5.1 风险识别框架

从以下维度识别风险：

```
1. 技术风险
   - 方法可能不工作
   - 实现难度超预期
   - 性能不达标

2. 资源风险
   - 计算资源不足
   - 数据获取困难
   - 时间超期

3. 科学风险
   - 假设可能错误
   - 实验设计缺陷
   - 评估指标不当

4. 外部风险
   - 竞争对手发布类似工作
   - 依赖库/工具出现问题
   - 不可抗力因素
```

### 5.2 风险评估矩阵

```markdown
# 风险评估矩阵

| 风险ID | 风险描述 | 可能性 | 影响 | 风险等级 | 缓解策略 | 应急计划 |
|--------|----------|--------|------|----------|----------|----------|
| R1 | [描述] | H/M/L | H/M/L | Critical/High/Medium/Low | [策略] | [计划] |
| R2 | ... | ... | ... | ... | ... | ... |

## 风险等级定义
- Critical: 可能性高 + 影响高 → 必须有缓解策略
- High: 可能性或影响高 → 需要缓解策略
- Medium: 需要监控
- Low: 可接受

## 缓解策略类型
1. 避免 (Avoid): 改变计划以避免风险
2. 转移 (Transfer): 将风险转移给第三方
3. 减轻 (Mitigate): 降低可能性或影响
4. 接受 (Accept): 接受风险并准备应急计划
```

## 常见问题

**Q: 假设太多怎么办？**
A: 优先级排序。使用 ICE (Impact, Confidence, Ease) 评分。每个研究问题聚焦 2-3 个核心假设。

**Q: 如何确定样本量？**
A: 使用功效分析 (Power Analysis)。给定效应量和显著性水平，计算需要的样本量。

**Q: 实验设计太复杂？**
A: 分阶段进行。先做最小可行实验 (MVE)，验证基本假设后再扩展。

**Q: 资源不够怎么办？**
A: 考虑：(1) 简化实验设计，(2) 使用小规模预实验，(3) 申请更多资源，(4) 调整研究范围。

**Q: 风险太多？**
A: 区分关键风险和一般风险。关键风险必须有缓解策略和 Plan B。

```markdown
# 示例：跨变量注意力机制研究

## 研究问题
多变量时序预测中如何有效利用变量间依赖关系？

## H1: 跨变量注意力假设

### 假设陈述
在多变量时序预测中，显式建模跨变量注意力机制相比独立变量
建模，可以将预测误差降低 10-15%。

### 变量
- IV: 注意力机制 (跨变量 vs 独立)
- DV: 预测误差 (MAE)
- CV: 模型深度、参数量、训练数据、优化器

### 实验设计

#### E1: 主要对照实验
- 实验组: 跨变量注意力模型 (CVA-Transformer)
- 对照组: 独立变量 Transformer (IV-Transformer)
- Baseline: LSTM, 基础 Transformer

#### 数据集
- Electricity (321 变量)
- Traffic (862 变量)
- Exchange (8 变量，低相关性对照)

#### 评估
- 主要指标: MAE, RMSE
- 统计检验: Paired t-test, α=0.05
- 重复: 5-fold CV, 每折 3 次运行

#### 资源
- 1x V100 GPU
- 约 20 GPU-hours
- 预计 3 天

#### 风险
- R1: 变量间相关性弱 → 缓解: 在低相关性数据集上测试
- R2: 过拟合 → 缓解: 早停、正则化、交叉验证
```
